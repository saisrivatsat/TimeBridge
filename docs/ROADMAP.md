# Roadmap

The roadmap is intentionally issue-driven. A feature moves into a release only
after its user problem and acceptance criteria are documented.

## 0.1 — Useful foundation

- [x] Compare up to six locations
- [x] Configure preferred hours
- [x] Find continuous shared windows
- [x] Share a plan through the URL
- [x] Add automated time-zone tests
- [x] Use 30-minute precision for half-hour time zones
- [x] Filter options by meeting length
- [x] Rank fair start times across 1, 7, or 14 days
- [x] Handle 23- and 25-hour daylight-saving transition days
- [x] Balance inconvenience across recurring weekly meetings
- [x] Produce a copyable weekly rotation
- [ ] Complete cross-browser and screen-reader checks
- [ ] Publish the first Netlify deployment

## 0.2 — Better planning

- [ ] Name and save multiple availability presets locally
- [ ] Export a selected window as an `.ics` calendar event
- [ ] Add copyable summaries for chat and email

## Later, if users ask

- Localized interface and 24-hour clock preference
- Recurring overlap finder
- Embeddable read-only plan
- Community-contributed city aliases

# Contributing to TimeBridge

Thank you for helping make cross-time-zone planning more considerate.

## Before coding

1. Search existing issues and discussions.
2. For a behavior change, open or claim an issue with a clear user problem.
3. Keep pull requests focused on one outcome.

## Local workflow

```sh
npm run dev
npm run check
npm test
npm run build
```

Pull requests should include tests for calculation changes and screenshots for
visible interface changes. Verify keyboard navigation and narrow-screen layout
when touching the interface.

## Commit style

Use short, imperative subjects such as `Add overnight availability tests`.
Explain the reason for non-obvious changes in the commit body or pull request.

By participating, you agree to follow the [Code of Conduct](CODE_OF_CONDUCT.md).
